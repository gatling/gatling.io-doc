## Reload locations without restarting the Control Plane

The Private Control Plane can now apply changes to `locations`, `default` and `description` without restarting, so builds in progress are not interrupted. This is opt-in:

```hocon
control-plane {
  configuration {
    scan = true # (optional, default: false)
  }
}
```

When enabled, the Control Plane checks its configuration file every few seconds and applies location changes to subsequent runs. Any other change, or an invalid file, is rejected and logged, and the Control Plane keeps its current configuration. `configuration.scan` itself is only read at startup.

When omitted, the configuration is only read at startup (unchanged behavior). See [Configuration hot-reload]({{< ref "/reference/deploy/private-locations/introduction/#configuration-hot-reload" >}}).
