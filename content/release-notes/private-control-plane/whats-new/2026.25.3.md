## AWS Private Locations deploy load generators with EC2 Fleet

AWS Private Locations now deploy load generators with [EC2 Fleet](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/ec2-fleet.html) instead of `RunInstances`. Load generators no longer have to fit in a single subnet: when a subnet or Availability Zone runs out of capacity, the fleet places the remaining ones in your other configured subnets, so runs fail less often for capacity reasons.

We recommend granting the EC2 Fleet IAM permissions. Without them, the Control Plane logs a warning and falls back to `RunInstances`, without these capacity benefits. See the [upgrade guide]({{< ref "/release-notes/private-control-plane/upgrading/to-2026.25.3" >}}).

## Spot Instances fall back to On-Demand

We recommend On-Demand Instances, the default: AWS can reclaim Spot Instances during a test, which interrupts the run.

If you still use Spot Instances, set `spot = "preferred"` instead of `true`: the Control Plane requests Spot Instances first and fills any missing load generators with On-Demand Instances. `"preferred"` requires the EC2 Fleet permissions.
