## AWS Private Locations deploy load generators with EC2 Fleet

AWS Private Locations now deploy load generators with [EC2 Fleet](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/ec2-fleet.html) instead of `RunInstances`. Load generators no longer have to fit in a single subnet: when a subnet or Availability Zone runs out of capacity, the fleet places the remaining ones in your other configured subnets, so runs fail less often for capacity reasons.

EC2 Fleet requires new IAM permissions. Without them, the Control Plane logs a warning and falls back to `RunInstances`. See the [upgrade guide]({{< ref "/release-notes/private-control-plane/upgrading/to-2026.25.3" >}}).

## Fall back to On-Demand when Spot capacity is unavailable

Set `spot = "preferred"` to request Spot Instances first and fill any missing load generators with On-Demand Instances:

```hocon
control-plane {
  locations = [
    {
      id = "<location-id>"
      type = "aws"
      spot = "preferred" # true, false or "preferred"
    }
  ]
}
```

`"preferred"` requires the EC2 Fleet permissions.
