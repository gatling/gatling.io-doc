## Release Notes

### 1.29.0 (2026-11-16)

#### Gatling 3.16.1

See release notes [3.16.1](https://github.com/gatling/gatling/milestone/144?closed=1).

#### Features

* SH-1073: Load generators running Gatling 3.16 now ship the JDBC and Kafka plugins
* SH-1068: Binary repositories: support GitLab Package Registry
* SH-1069: Binary repositories: use the configured HTTP proxy

#### Fixes

* SH-1070: TCP connections by state monitoring: fix the monitoring on arm64 load generators. If the native library can't be loaded, monitoring is now disabled with a warning instead of failing
* TCP connections by state monitoring: fix missing stats for IPv6 targets, and reduce the monitoring overhead on load generators with many open connections
* SH-1072: TCP connections by state monitoring: stop collecting and displaying the bound, idle and close states, which were always empty
